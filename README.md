## Ncaori Mail+ (`ncaori.my.id`)

**What it was:** A free temporary email service (`temp-mail.ncaori.my.id`) built to generate disposable addresses for automated testing and registration workflows.

**Current status:**

- **Operational** — the service is still running and addresses can still be generated.
- **Deprecated** — no active development, no new features, no maintenance guarantees.
- **Flagged** — `ncaori.my.id` and associated domains are listed as disposable/forwarding by multiple email-validation services (UserCheck, Check-Mail.org, etc.). This is expected and intentional. The domains are designed to be disposable.
- **Not under review** — there is no pending application, appeal, or review process to delist the domains. The disposable classification is accepted as-is.

**What this means if you are a developer:**

- The service may be slow or unreliable.
- API endpoints may change without notice.
- Do not use it for production systems or accounts you care about.
- If you need a reliable temp-mail provider, use a maintained alternative.
